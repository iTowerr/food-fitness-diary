# Дневник питания и тренировок

Учебное настольное приложение: дневник питания и тренировок с расчётом
калорий и нагрузки. **Разработал: Дерябин Захар Олегович, группа 22О.**

Стек: **Python 3.12 + Tkinter** (интерфейс написан кодом вручную, без
конструкторов) + **SQLite** (встроенная БД, файл `food_diary.db`).

## Запуск

- Двойной клик по ярлыку **«Дневник питания и тренировок»** на рабочем столе, **или**
- `python main.py` из папки проекта.

## Возможности по ролям

**Пользователь:** дашборд с расчётами (норма калорий от веса, съедено,
сожжено, баланс, нагрузка за 7 дней), дневник питания, дневник тренировок,
редактирование своего веса, раздел «О программе». Видит только свои записи.

**Администратор:** всё выше + управление пользователями (добавление,
редактирование, удаление, роли), просмотр журнала действий. Видит записи
всех пользователей.

## База данных (6 связанных таблиц, PK/FK)

```
users (id PK) ──< meals (user_id FK, product_id FK) >── products (id PK)
   │  └─────< workouts (user_id FK, exercise_id FK) >── exercises (id PK)
   └─────────< action_log (user_id FK)
```

Тестовых данных: 4 пользователя, 12 продуктов, 12 упражнений,
24 записи питания, 15 тренировок, 7+ событий журнала — итого 70+ записей.
Целостность внешних ключей проверяется кнопкой «Проверить связи БД»
в разделе «О программе» (PRAGMA foreign_key_check).

## Формулы расчёта

- Калории еды: `ккал/100г × граммы / 100` (+ пересчёт Б/Ж/У)
- Калории тренировки (ACSM): `MET × 3.5 × вес(кг) / 200 × минуты`
- Нагрузка в баллах: `MET × минуты / 10`
- Суточная норма: `вес × 33` (упрощённая формула поддержки веса)
- Цель нагрузки: 300 баллов в неделю (≈ рекомендация ВОЗ 500–1000 MET-мин)

## Окна (больше 3, с переходами)

1. Окно входа (анимированный логотип, живой фон)
2. Главное окно (шапка + хлебные крошки + подвал + экраны)
3. Диалоги добавления/редактирования: запись питания, тренировка,
   пользователь
4. Окно сквозного поиска по всему приложению

## Экраны

Главная (дашборд), Дневник питания, Дневник тренировок, Пользователи *,
Журнал действий * (* — только админ), О программе
(ФИО, группа, статистика БД, интерактивная палитра). На каждом экране
есть работа с данными: ввод, редактирование, удаление, расчёты, фильтры.

## Анимации (обязательные)

1. **Кнопки** — плавная смена цвета при наведении и нажатии (интерполяция
   цвета, эффект «проваливания»), `ui.py → HoverButton`.
2. **Объект в окне** — кольцевые индикаторы на дашборде анимированно
   заполняются (ease-out), логотип покачивается на окне входа, экраны
   «въезжают» справа при переходах (slide-in), спиннер на логотипе,
   «тряска» формы при неверном пароле.
3. **Фон главного окна** — живые частицы: пузырьки всплывают, большие
   «орбы» тонут, работают постоянно сами (`ui.py → Particles`).
   Дополнительно: часы в подвале обновляются каждую секунду.

## Навигация и поиск

- **Хлебные крошки** под шапкой: «Главная / Дневник питания» — кликабельны.
- **Сквозной поиск** (Ctrl+F или поле в шапке) — ищет по продуктам,
  упражнениям, записям, пользователям; двойной клик по результату
  переходит в нужный раздел с применённым фильтром.
- **Фильтрация**: период (все/сегодня/7/30 дней), тип приёма, группа
  мышц, пользователь (у админа), живой поиск по названию.
- **Сортировка**: клик по заголовку любого столбца таблицы (▲/▼).

## Дизайн: палитра и шрифты (обоснование)

Палитра — тёмная аналоговая схема с двумя акцентами:

| Цвет | HEX | Роль |
|------|-----|------|
| Угольный фон | `#10181D` | снижает нагрузку на глаза вечером |
| Панели | `#1A2730` / `#22333F` | группировка контента |
| Мятно-зелёный | `#37C978` | здоровье, питание, успех |
| Оранжевый | `#FF9F43` | энергия, тренировки |
| Красный | `#E9575B` | только ошибки и удаление |

Зелёный и оранжевый — «холодный + тёплый» контраст: питание и тренировки
читаются как два разных раздела мгновенно. Тёмный фон подчёркивает
акценты и подходит приложению, которым пользуются после работы/зала.

Шрифтовая пара (принцип fontjoy/mixfont — «гротеск + тот же гротеск
другим весом + моноширинный для данных»):

- **Segoe UI Semibold** — заголовки (задаёт иерархию);
- **Segoe UI** — основной текст (максимальная читаемость на экранах Windows);
- **Consolas** — таблицы/цифры (моноширинные цифры не «прыгают»).
